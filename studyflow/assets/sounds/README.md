# Ambient Sounds

Please add the following MP3 files to this directory for the Focus Mode mixer to work:

- `rain.mp3`
- `forest.mp3`
- `fire.mp3`
- `stream.mp3`

You can find royalty-free sounds on websites like [Pixabay](https://pixabay.com/sound-effects/) or [Mixkit](https://mixkit.co/free-sound-effects/).
